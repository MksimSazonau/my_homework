# my_homework
# Анализ олимпийской статистики на SQL

Учебный репозиторий Максима Сазонова с SQL-запросами
для анализа результатов летних и зимних Олимпийских игр.

Профессиональный опыт в баскетболе стал основой моего интереса
к спортивной аналитике. Здесь я развиваю навыки работы
с данными и решения аналитических задач на PostgreSQL.

## Инструменты

- PostgreSQL
- DBeaver
- Visual Studio Code

## Аналитические задачи

- Ранжирование стран по количеству наград.
- Сравнение результатов страны с предыдущими Олимпийскими играми.
- Расчёт накопительного количества наград спортсмена.
- Поиск стран с серебряными и бронзовыми наградами без золотых.
- Анализ возраста участников по видам спорта.
- Объединение данных летних и зимних Олимпийских игр.

## Используемые возможности SQL

- JOIN и объединение данных через UNION ALL.
- GROUP BY, HAVING и агрегатные функции.
- Условные вычисления с CASE WHEN и COALESCE.
- Подзапросы, CTE и EXCEPT.
- Оконные функции ROW_NUMBER, DENSE_RANK, LAG и SUM OVER.

## Данные и запуск

Запросы используют таблицы:
- athletes_summer_games — результаты летних Олимпийских игр;
- olympic_winter_results — результаты зимних Олимпийских игр;
- olympic_regions — справочник стран и кодов NOC.

Исходные данные и скрипты их загрузки пока не включены
в репозиторий. Для запуска требуется PostgreSQL с указанными
таблицами. Названия схем нужно адаптировать к своей базе.

## Особенности расчётов

В ряде запросов подсчитываются записи о наградах спортсменов.
В командных дисциплинах это может учитывать награду каждого
участника, поэтому результат не равен официальному медальному
зачёту стран.

Репозиторий развивается в процессе обучения. Некоторые файлы
содержат несколько вариантов решения одной задачи.
